Prompt Visualization

Exploring how LLMs constrain token generation probability spaces

These interactive 3D visualizations demonstrate fundamental concepts in how large language models generate text. They show how different prompting techniques and reasoning strategies constrain the probability cone — the region of possible next tokens the model considers — making outputs more predictable or more diverse.

Chain of Thought

See how step-by-step reasoning works. Each token in a chain of thought narrows the probability cone, eliminating vast regions of the solution space. Compare direct answers, broken chains, and complete reasoning flows.

Understand how examples anchor the embedding space. Zero-shot operates on the full probability space, while few-shot examples create constructive interference, narrowing the cone. See what happens when examples conflict.
